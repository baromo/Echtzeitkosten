# ECHTKOSTEN

Eine statische, deutschsprachige Website für verständliche Autokosten. Sie läuft ohne Servercode, Anmeldung oder kostenpflichtige Bibliotheken.

## Seiten

- `index.html`: Gesamtkosten eines einzelnen Autos
- `vergleich.html`: Zwei Szenarien mit gleicher Haltedauer und Jahresfahrleistung vergleichen, etwa Benzin gegen Elektro oder Auto behalten gegen wechseln
- `behalten-oder-wechseln.html`: Schritt für Schritt erklären, welche Werte in einen fairen Vergleich gehören
- `methodik.html`: Formeln, Annahmen und Grenzen der Schätzung offenlegen

## Lokal öffnen

Öffne `index.html` in einem aktuellen Browser. Es ist kein Build-Schritt nötig. Für die anderen Seiten nutze die Navigation oder öffne die jeweilige HTML-Datei.

## Berechnung

Die Eingaben werden im Browser verarbeitet und nicht an ECHTKOSTEN übermittelt. Beispielwerte sind ausschließlich veränderbare Startwerte. Die Rechnung umfasst Wertverlust, geschätzte Finanzierungszinsen, Energie, Versicherung, Kfz-Steuer sowie Wartung und Reparaturen.

Bei Vergleichen gelten dieselbe Haltedauer und dieselbe Jahresfahrleistung für beide Szenarien. Für ein bereits vorhandenes Auto ist mit „Wert heute“ sein heutiger Marktwert gemeint, nicht sein früherer Kaufpreis.
